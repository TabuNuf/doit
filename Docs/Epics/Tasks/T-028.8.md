# T-028.8: Project page: opens from the project's name; header, three cards, Waiting on you

## Description

### Goal
One page shows a project's state: what is active, what waits on the designer and what comes next.

### Decided
1. The project's name in web/leftPane.js becomes a button (`data-project-page`) that clears the selected task and epic and sets `S.projectPage`.
2. `detailPane` in web/render.js shows the page when no task and no epic shows: for `S.projectPage`, or for the one project selected in the top bar.
3. New web/projectPage.js builds, from `S.data` alone, the Specification's Project page down to the Waiting on you list.
4. Waiting: open tasks owned by human that no open task's `blocks` names.
