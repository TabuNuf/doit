# T-033.5: Read the game type list from GameTypes.md

## Description

Goal: the app knows the fixed list of game types and each type's neighbours, so entries and profiles can be checked against it.

Add `src/domain/gameTypes.js`, pure: `parseGameTypes(text)` reads lines `- <type>: <neighbour>, <neighbour>` into `[{type, neighbours}]` in lower case; `checkTypes(value, list)` accepts one or two known types (array or comma string) and throws `ContactError` otherwise; `typeWeight(type, profileTypes, list)` gives 1 for a profile type, 0.5 for a neighbour of one, else 0. Add `src/store/gameTypeShelf.js`: `GameTypeShelf.list()` reads `GameTypes.md` from the marketing project's docs, found the way `TemplateShelf` finds its folder; a missing file is an empty list. `GameCatalog` takes it as a `types` port and exposes `types()`. Add `doit game-types` to `GamesCli` and `help.js`, and wire the shelf in `root.js`.

Do not change `gameEntries.js` in this task.

Run `npm test` and report its output. The task is done only when it passes.
