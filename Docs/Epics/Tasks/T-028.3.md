# T-028.3: epicDoc.js: read an epic's text into header, findings and sections, old shapes too

## Description

### Goal
One pure function turns an epic file's text into the parts the epic page shows and loses no text, so epics written before the new rules still read whole.

### Decided
- `parseEpicDoc(text)` in a new web/epicDoc.js returns in short, why, the status word and any words after it, the facts, loose header text, the findings and every `##` section in file order.
- Every fallback under Old formats holds, with one fixture per old shape.
- What does not parse stays markdown text in its place.
- Approved: web/markdown.js may nest an indented list row under the item above.
