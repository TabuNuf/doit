# T-033.7: Game profiles carry types, personas and beats

## Description

Goal: a game profile says what the game is, who plays it and when outreach should land.

In `src/store/profileShelf.js`, `parseProfile` also reads a `Types:` line (comma list); `Beat: YYYY-MM-DD <name>` lines, repeatable, into `beats` sorted by date; and a `## Personas` section where each `### <name>` block holds `Who:`, `Types:` and `Scores: achiever 3, explorer 1, socialiser 0, killer 0, pressure 3, creation 2`, into `personas` as `[{name, who, types, scores}]`. A bad date, a score outside 0 to 3 or a missing score goes into the profile's `problems` list as text; nothing throws. `save` accepts `types`. The template gains the new lines as comments. `doit profiles` prints the types, the persona names and the next beat; `doit profile set <project> types=a,b`. Update `help.js`.

Do not check types against the type list here: `ContactBook` stays unaware of it.

Run `npm test` and report its output. The task is done only when it passes.
