# T-026.1: A task knows it is hidden, and the board's view and list leave hidden tasks out

## Description

Goal: an open task (todo, progress, backlog) whose epic is not open is hidden, so parked and closed work is offered nowhere. Design.md, section Epics, "Open tasks of an epic that is not open are hidden".

Files: `src/domain/task.js`, `src/domain/taskEdit.js`, `src/domain/board.js`, `src/domain/outreach.js` (`#taken`), `test/board.test.js`, `Docs/Architecture.md` (the task.js and board.js module lines, `Board` in the class diagram).

Steps:
1. task.js: `makeTask` sets `epicOpen` (the epic is not `parked`, not `completed`, status neither Parked nor Done) and `hidden` from a new `isHidden(task)`: epic not open and `tabOf(state)` is open. `applyChanges` sets `hidden` again after a change.
2. `Board.view` takes `hidden` (default false) and leaves hidden tasks out without it. `Board.list` passes `hidden: true` when `epic` is given.
3. `#taken` passes `hidden: true`.

Do not change the store, `Board.get` or the sweep; neither field is written to the task file. `board.js` has 218 lines and its guard fails at 220: edit lines in place.

Run `npm test` and report its output. The task is done only when it passes.
