# T-028.14: A sibling notes file is not listed as an epic

## Description

### Goal
A notes file kept beside an epic (`EPIC-<nnn>-<name>.notes.md`) never shows as an epic. Up for removal from every epic list.

### Seen
Box Trainer, 2026-11-22: the board shows two EPIC-144 cards, "Player objectives" 1/22 and "Player objectives, notes" 0/0. `doit epics box-trainer` prints both. The second is `Docs/Epics/EPIC-144-player-objectives.notes.md`.

### Cause
`ProjectFiles.epicFiles` in src/store/projectFiles.js takes every `EPIC-<digits>*.md`, and the notes file's heading `# EPIC-144: Player objectives, notes` parses as an epic title. EPIC-138's notes file is skipped only because its heading has no colon.

### Decided
1. `epicFiles` passes over a name ending in `.notes.md`, in Epics/, Parked/ and Completed/.
2. That one place covers the CLI, the epic cards and the project page.
3. The file stays a document in the Docs tree.

### Files
- src/store/projectFiles.js
- test/ (the store's epic file test)

### Design
EPIC-028, Specification, Epic page. Design.md, Epics.

### Leave alone
src/store/docsFolder.js and the notes files themselves.

### Check
```
npm test
```
Run it and report its output. The task is done only when it passes.
