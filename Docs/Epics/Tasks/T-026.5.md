# T-026.5: The page keeps hidden tasks out of the Open tab, the due badge and the waiting list

## Description

Goal: the page needs the hidden tasks, for a parked or closed epic's page and its list, and shows them nowhere else. Design.md, sections Epics and Tasks (Open tab).

Files: `src/server/server.js` (the `GET /api/board` route), `web/state.js` (`visible`, `dueSoonTasks`), `web/projectPage.js` (`waiting`), `test/server.test.js`, `test/web.test.js`, `test/projectPage.test.js`, `Docs/Architecture.md` (the server and `web/` module lines).

Steps:
1. The route calls `board.view` with `hidden: true`.
2. `visible()` drops a task with `t.hidden` while no epic is selected (`S.epic` empty). With an epic selected the epic filter decides, so its hidden tasks are listed.
3. `dueSoonTasks()` and `waiting()` drop hidden tasks.

Do not compute the rule in `web/`: the page reads `t.hidden` and never looks at an epic's status or folder for this. The Completed and Archive tabs, the epic page and `GET /api/claude` stay as they are. No web file over 300 lines.

Run `npm test` and report its output. The task is done only when it passes.
