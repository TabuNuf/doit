# T-026.2: Closing an epic archives its completed tasks and leaves the open ones hidden

## Description

Goal: a close no longer archives To-do, In progress and Backlog tasks, so a reopened epic gets them back in the state they had. Design.md, section Epics, Close epic.

Files: `src/domain/epicMoves.js` (`close`), `src/cli/help.js` (the `epic close` line), `web/epicView.js` (the confirm text in `closeEpic`), `test/board.test.js`, `test/cli.test.js`, `Docs/Architecture.md` (the epicMoves.js and board.js module lines).

Steps:
1. `close` archives only the epic's tasks in state done, with today's reason, and returns their count. Open tasks are not written.
2. Help line: "archive the epic's completed task files, leave open ones hidden, set it Done, move it to Completed/".
3. Confirm text: "Close <id>? Its completed tasks move to the archive, its open tasks are hidden, and it moves to Completed."
4. Update the tests that expect every task archived at a close.

Do not change the Check in play gate, `planEpicMove`, `restored` (epics closed before this change still get their archived tasks back) or the store.

Run `npm test` and report its output. The task is done only when it passes.
