# T-026.6: The list says why when the selected epic is parked, completed or archived

## Description

Goal: when Tabu clicks a parked or closed epic, its open tasks show only there. A line says so and how to bring them back, since every warning in the app says what is wrong, why and what to do (Design.md, section Claude view).

Files: `web/render.js` (`listPane`), `web/style.css` only if no existing class fits, `test/web.test.js`.

Steps:
1. In `listPane`, when `S.epic` is set and the listed tasks hold one with `t.hidden`, render one line above the Active section: "<EPIC-id> is <place>, so its open tasks show only here. Drag it onto the open epics to bring them back."
2. `<place>` is "parked" when the epic is in `S.data.parkedEpics`, "archived" or "completed" from its `S.data.closedEpics` entry's `archived` flag, else "not open".
3. Use the muted note style the empty states use. A new rule in `style.css` uses the existing colour tokens only.

Do not change `web/state.js`. This task is unchecked in play: the look is on the Check in play list (T-026.7).

Run `npm test` and report its output. The task is done only when it passes.
