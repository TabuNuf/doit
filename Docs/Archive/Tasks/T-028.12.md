# T-028.12: Closing an epic waits for its open Check in play task

## Description

### Goal
An epic cannot close while the designer's Check in play task is open, so the check stays on the waiting list.

### Decided
1. `parseEpic` in src/store/markdown.js returns `check`: the task id in the Test plan line `- Check in play: T-<nnn>.<n>`, else null.
2. `EpicMoves.close` in src/domain/epicMoves.js throws while that task is neither done nor archived: "<epic> waits for <task>, Check in play. Finish it, then close." It runs before any task is archived.
3. That one place covers the CLI, the button and the drags.
4. No line, or "none": the epic closes as today.
5. Docs/Architecture.md names both changes.
