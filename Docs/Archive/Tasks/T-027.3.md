# T-027.3: Detail pane: agent, model and effort editable on a Claude task, not shown on a human one

## Description

For: batch-builder, Sonnet 5.5, medium

Goal: the task detail pane shows and edits the three fields of T-027.1 for a task owned by Claude and shows nothing of them for a task owned by a human. Hiding is display only: the page never sends the fields when the owner changes. Design: `Docs/Design/Design.md`, section Tasks, "Who builds it" and Detail pane.

Steps:
1. New `web/assignment.js`: `assignmentRows(t)` returns "" unless `t.owner === "ai"`, else three `<dt>/<dd>` rows: Agent, a text input `id="ag"`; Model, a text input `id="mdl"` with a `<datalist>` of `Haiku 5.5`, `Sonnet 5.5`, `Opus 5.5`, `Fable 5.2`; Effort, a `<select id="eff">` with an empty first option shown as `-` and `low`, `medium`, `high`, `xhigh`, `max`, the stored one selected. Each control has an `aria-label`. Stored values are escaped. The module must import in Node without a DOM (`test/contactPane.test.js` shows how pane modules are tested).
2. `web/render.js` `detailPane`: `${assignmentRows(t)}` after the Type row. No web file may pass 300 lines (`test/web.test.js`).
3. `web/events.js`, the `change` listener, beside `blk`: `ag`, `mdl`, `eff` call `patch(t, { agent | model | effort: value.trim() })`. The `PATCH /api/tasks` route already hands the body to `Board.update`.
4. `web/style.css` only if the rows need it; use the existing tokens.
5. `Docs/Architecture.md`: `assignment.js` in the `web/` file list.

Tests (new `test/assignmentPane.test.js`): for an ai task the HTML has the three controls with the stored values, the stored effort selected; for a human task with all three stored, `assignmentRows` returns ""; a value holding `"` and `<` is escaped; `render.js` calls `assignmentRows` and `events.js` patches `agent`, `model` and `effort` (read the source as `test/headline.test.js` does).

Commit as `T-027.3: <summary>`, staging only your paths. Run `npm test` and report its output. The task is done only when it passes. Do not start the server.
