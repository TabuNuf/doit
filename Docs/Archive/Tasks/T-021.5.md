# T-021.5: Contact import reads every column of the New Streamers sheet

## Description

Video 04:41-05:01: reach shows 0 though the sheet has a size, and every contact has only YouTube. Cause found in contactImport.js: the sheet's email column is named Contact, only the Youtube column is read as links, the reach is a bucket that reachOf rejects, and dates are not ISO. 210 emails and about 450 channel links were dropped.
