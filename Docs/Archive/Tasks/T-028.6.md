# T-028.6: Task page: Properties box, every value a control, assignment greyed on a designer task

## Description

### Goal
Every value of a task is changed in one box that looks the same for both owners, so a change of owner moves no control.

### Decided
1. New web/taskProps.js takes the `<dl class="kv">` block out of `detailPane` in web/render.js and builds the Specification's properties box, head line included.
2. web/assignment.js returns its three rows for both owners. For owner human: disabled, labels muted, placeholder "used when Claude owns it", stored values shown.
