# Deviations from the standard

The rules of the standard this game does not follow, each with its reason. The sync never overwrites this file. A rule listed here is still pulled into the copy; this file says why the game sets it aside.

| Rule (file, section) | What this game does instead | Why | Until |
|---|---|---|---|
| `Core/01-Tasks.md`, The documents: a task is a checklist line in its epic file | A task may also have a file, `<Docs>/Epics/Tasks/T-<nnn>.<n>.md`, with its state, owner, deadline, description and comments; the checklist line stays the title and done-when | The board needs fields and comments per task, and keeping them out of the epic file keeps epic files short for Claude to read | Permanent |
